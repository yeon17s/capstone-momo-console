# 백엔드·프론트엔드 공유 자료 — 먼저 읽기

이 폴더는 공개 voraus-AD 분석 결과로 와이어프레임과 대시보드를 개발하기 위한 **오프라인 공유 묶음**이다. 원본 CSV/설정/보고서는 이름·폴더 구조·내용을 유지해 복사했다. 실험 재실행용 전체 프로젝트와는 목적이 다르며 Python 가상환경, 대용량 원본 Parquet, 학습 모델은 포함하지 않았다. 원본 프로토콜의 과거 로컬 경로는 실행 당시 기록이다.

## 2. 초기 화면 구성과 필터

1. **데이터 개요:** 정상1367/이상755, 전체2122사이클. category별 수는 `category_counts.csv`에서 읽는다. 현재 자료는 공개 Yu-Cobot 기록이며 실제 xArm 실시간 상태가 아니다.
2. **실험 성능:** 먼저 `model_comparison.csv`를 `scope=all_12`로 필터한다. A/B/C, cycle/action, algorithm을 선택하고 `macro_category_auroc`, `pr_auc_ap`, `recall`, `normal_fpr`, `fp/n_normal`을 함께 표시한다. Confusion Matrix는 `tn/fp/fn/tp`를 그대로 사용한다. 전체AUROC(`auroc`)와 유형별 단순평균(`macro_category_auroc`)은 다른 지표다.
3. **유형별 비교:** 동일한 representation/input_set/algorithm을 고정한 `category_metrics.csv`를 사용한다. 모든 유형 행에 동일 평가 정상419개가 들어가므로 행별 n_normal을 합산하지 않는다.
4. **사이클 목록:** `cycle_predictions.csv`에서 representation/input_set/algorithm 하나와 `split=evaluation`을 고정하면1174행(정상419+이상755)이다. 전체 파일은18모델×2122개로 같은 sample이 반복된다. UI의 사이클 식별자는 sample, 모델별 결과 키는 sample+representation+input_set+algorithm이다.
5. **특징 그룹:** combination/algorithm/representation을 키로 사용한다. G0전류·전압, G1목표/실제위치, G2목표/실제속도, G3위치오차, G4속도오차, G5관절iq. `configuration_catalog.csv`로 입력 수를 확인한다. 알고리즘이 다른 결과를 단순한 센서 효과로 비교하지 않는다.
6. **개별 특징:** importance_summary를 protocol/algorithm/input_set으로 필터한 후 mean_importance 내림차순 또는 mean_rank_position 오름차순으로 읽는다. 기본 참고는 protocol=setting, algorithm=random_forest, input_set=full이다. top10_folds/positive_folds/std_importance를 함께 표시한다. 학습 중요도 MDI와 순열 AUROC 감소는 별도 지표다.
7. **특징 축소:** Top-K 실험의 키는 protocol+fold+algorithm+input_set+k다. k는 숫자 문자열 또는 `all`이다. fold 평균과 pooled OOF는 합치지 않는다. `inner_selected_policy_metrics.csv`는 학습 내부에서 선택한 K의 결과이며 평가에서 가장 좋은 K를 고른 결과가 아니다.

## 3. 그래프 데이터의 의미

- `results_03/aligned_timeseries.csv`: 마찰(category0)/관절 추가하중(category1)의 setting별 기존 EDA다. setting/action/active/occurrence/signal/group으로 필터하고 x=progress_percent, y=median, 띠=q10~q90를 그린다. group은 NORMAL/PRE_A/ANOMALY 등 실제 CSV 값을 확인한다. 같은 setting·Action·active·occurrence끼리 비교한다. progress_percent는 구간 내 정렬 진행률로 실제 시각이 아니다. 실시간 History 원시 샘플로 저장하거나 초 단위 시간축으로 표시하지 않는다.
- `action_family_overview.csv`: category/action/active/family별 설명 통계다. effect=(이상중앙값−정상중앙값)/정상IQR, cycle_effect는 전체 Cycle의 동일 척도, normal_shift는 정상 배치 간 변화의 비교치다. 관절 계열은6관절의 부호 있는 중앙값이라 원인 관절 정보가 아니다. duration_fault/normal은 구간 지속시간 중앙값이다. effect는 탐지확률/AUROC/센서 원시값이 아니다.
- 원본 보고서에 직접 삽입된 PNG는 상대경로대로 함께 복사했다. 상세 전체42개 시계열 그림과 원본 대용량 특징 캐시 등은 전체 프로젝트를 참고한다.

## 4. 표시 전에 합의할 의미

| 필드/내용 | 올바른 해석 |
|---|---|
| category/anomaly | 공개 데이터의 실제 라벨. 모델이 예측한 고장 유형이 아님 |
| setting/variant_name | 실험 조건·정상 수집 배치. 위험도/심각도 아님 |
| prediction | 해당 모델·임계값에서 정상/이상 판정 |
| Baseline score | 모델별 이상 점수. 확률·미래 고장 위험도가 아니며 모델 간 직접 비교 불가 |
| threshold | 실험별 임계값. UI에서 전역 임계값으로 통일하지 않음 |
| 정상 FPR | 정상 중 이상으로 판정한 비율. fp/n_normal 함께 표시 |
| PR-AUC | 주 지표는 pr_auc_ap(Average Precision); 사다리꼴 적분과 구분 |
| mean_importance | Tree/RF 불순도 감소 중요도. 물리적 원인 중요도 아님 |
| TRUE/FALSE 문자열 | 문자열을 boolean으로 명시 변환. 단순 문자열 존재 여부로 판정하면 False도 참이 됨 |
| 빈 셀/NaN | 미평가·정의 불가 가능성. 자동으로0점/0위험 처리하지 않음 |

현재 구현은 현재 상태의 이상 탐지와 지도학습 특징 선택이다. 대시보드의 '고장 진단 유형', '미래 K-cycle 위험도', 'RUL', '실시간 조기 경보', '실제 xArm 성능'을 완료 기능처럼 표시하지 않는다. 공개 데이터 실험 결과 화면과 향후 실측 장비 상태 화면을 구분한다. API/실시간 스트림/History DB 저장 형식은 이 묶음에서 구현·확정하지 않았다.

## 5. 평가 조건과 현재 알려진 문제

- Baseline: PRE_A 정상711학습/237보정, 평가 정상419+이상755. 정상 보정 목표 FPR5%이며 외부 배치에서 보장되지 않는다. 설정은 baseline_config.json 및 results_05_baselines/frozen_protocol.json이다.
- Ablation: 기존 분할을 재사용한72조건. 상세 입력/설정은 results_06_feature_ablation/frozen_ablation_protocol.json이다.
- 지도 특징 선택: 정상·이상을 학습한 별도 Cycle/setting 외부3fold, 학습 내부 순위/K/임계값 분리. 임계값은 내부 Balanced Accuracy 기준이며 Baseline과 직접 우열 비교하지 않는다. 설정은 results_08_feature_selection/feature_selection_protocol.json이다.
- 지도 실험의 정상은 OOF 전체1367개로 Baseline 평가 정상419개와 다르다. Fold 평균 AUROC와 pooled OOF AUROC를 별도 표시한다. 정상 배치별 크기 차이 때문에 전체FPR과 배치FPR 단순평균도 다르다.
- RF full의 setting fold2에서는 AUROC약0.609, 정상98/100개 오탐이 있었다. 소수 정상 배치에서FPR이 매우 높다. 높은 AUROC만 성과 카드로 표시하지 말고 FPR과 배치별 분포를 함께 보여준다.
- 이미 여러 번 열람한 공개 평가 데이터를 재사용했다. 모든 결과는 탐색적 참고이며 최종 독립 검증이 아니다. 전압의 높은 중요도를 물리적 고장 원인 감지로 단정하지 않는다.
- xArm 피드백 API·읽기 주기·센서 동기화·재현 조건은 미확인이다. iq는 산업용 참고이며 INA226 전체 전류와 다르다. 진동은 공개 데이터에 없어 효과를 평가하지 않았다.
