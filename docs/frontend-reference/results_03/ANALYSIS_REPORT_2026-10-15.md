# MOmO voraus-AD 후속 EDA — 2026-10-15

## 프로젝트 맥락

공개 Yu-Cobot 데이터에서 분석·모델 개발 근거를 만들고, 배송 후 Hiwonder xArm 2.0에 전체 DC 전류/전압과 위치 피드백, 진동 등을 직접 계측하는 프로젝트다. 공통 상태 특징과 장비별 보정은 검증할 연구 과제이며, 전이 성공을 전제하지 않는다. 공개 데이터는 자연 열화의 run-to-failure 이력이 아니므로 이번 결과는 이상 조건의 진단 신호 탐색이다. K-cycle 미래 고장 위험이나 RUL 성능을 의미하지 않는다.

## 기존 코드 검토

- 01: JOINT=1 고정, 정상 첫 100사이클·setting 첫 30사이클 선택, 사이클 전체 진행률 보간. 다른 관절의 이상을 관절 1 오차로 판단할 수 없고, 국소 피크가 Action 시점 차이와 섞인다.
- 02: 여섯 관절 오차는 계산했으나 setting 요약과 그래프는 관절 1 중심. action/active와 관절 iq 전류는 비교하지 않았다. 정상 전체를 EDA 기준으로 사용한 것은 가능하지만 모델 학습 기준과 구분해야 한다.
- test.py: action/active의 first()는 첫 행 정보만 보여주므로 사이클 전체에서 일정하다는 의미가 아니다.
- 원본 01/02와 기존 results_01/02는 보존했다. 새 코드로 기존 전체 전류 RMS와 관절 1~6 MAE를 다시 계산했으며, 기존 CSV와 최대 절대 차이는 2.22e-16이다(선택한 정상+마찰+하중 1,667사이클).

- 전체 robot_current와 motor_iq는 서로 다른 측정량이다. 합산/치환하지 않고 각 신호의 정상 대비 변화율을 계산했다. 전류 RMS·절대 피크, 오차 MAE·P95를 전체 사이클/active별/연속 Action 구간별로 저장했다.
- Action+active가 연속하는 구간마다 나누어 동일 Action 방문 번호끼리 60점 정렬. active=1 시계열 그래프는 7개 동작을 각 패널로 표시한다. 패널 폭은 실제 시간이 아니며 duration은 별도 CSV로 남겼다.
- 선택 데이터에서 1행뿐인 구간 212개는 시계열 보간에서 제외했으며 특징 CSV에는 보존했다. action=13, active=0의 1행 경계가 있어 action 홀짝으로 active를 대신하지 않았다.
- 반복 방문 번호가 2 이상인 구간은 0개. 누락/종료 Action은 data_quality.csv와 action_duration_summary.csv에서 확인 가능하다.
- 샘플 간격 중앙값의 사이클별 중앙값은 0.01006603초. 특징은 샘플 가중치로 계산했고 시간 가중 적분은 하지 않았다.

## 이번 실행에서 확인한 핵심 관찰

1. 대상 관절을 바로잡은 뒤에도 전체 사이클 위치 오차 MAE의 정상 대비 변화는 약 -3.8%~+2.3%, P95는 약 -3.7%~+2.8%였다. 위치 추종 오차가 모든 마찰/하중 조건에서 증가한다는 가설은 이번 결과로 지지되지 않는다. 제어기가 전류를 조절해 오차를 억제했을 가능성 등은 설명 후보이며 원인으로 확인한 것은 아니다.
2. 마찰 setting=7(A4_A, n=13)은 전체 전류 RMS +0.21%, 대상 관절 iq RMS +11.58%였다. 전체 사이클 전류 변화의 bootstrap 구간은 0을 포함하지만, iq RMS 차이의 구간은 약 +0.0923~+0.0974 A였다. 전체 전류만 보면 작게 보이는 조건이 있다는 사례다. 이것만으로 탐지 정확도를 산정하지 않는다.
3. 같은 setting=7에서 Action=1의 관절 iq RMS는 +16.96%, Action=7에서는 -34.16%였다. Action=9에서 전체 전류 RMS는 -0.72%, 대상 관절 iq RMS는 +12.74%였다. 동작별 변화 방향·크기가 달라 전체 사이클 요약이 국소 차이를 가릴 수 있다. RMS는 부호를 제거하므로 signed iq 파형도 함께 확인한다.
4. 하중 조건의 전체 전류 RMS는 +1.64%~+7.43%였지만 무게 순서대로 증가하지 않았다. 관절 1의 115g/231g/500g 조건은 각각 +4.83%/+4.44%/+3.50%였다. 하중에 대응하는 관절의 iq만 가장 크게 변한다고 볼 수도 없다. weight_all_joints.png에 여섯 관절의 변화를 함께 남겼다.
5. Action=7의 setting=28에서 대상 관절 위치 오차 P95가 +43.39%였지만 절대 차이는 약 0.000032 rad다. 작은 정상 기준 때문에 변화율이 커 보이는 사례이므로 큰 백분율만으로 핵심 특징을 선택하지 않는다.

이 관찰들은 현재 CSV에 대한 설명이다. 데이터/분석 조건을 바꿔 재실행하면 아래 표와 수치를 다시 검토해야 한다.

Action별 비교는 같은 action/active/방문 번호의 사이클 특징끼리 한다. 작은 종료 구간에는 이상 사이클 수가 3 미만인 조합 31개가 있다. 이 구간의 bootstrap 결과는 특히 불안정하다.

95% 구간은 seed=20261015, 사이클 재표집 1,000회의 중앙값 차이 percentile bootstrap이다. 변화율 그래프의 구간은 이 차이 구간을 관측 정상 중앙값으로 나눈 값이다. 같은 실험 배치 내 사이클 상관을 보정하지 않았고 다중 비교 보정도 하지 않았다. 0을 제외하는 구간도 확증적 유의성이나 일반화 증거로 쓰지 않는다. 시계열 음영은 사이클 간 10~90% 분포이며 신뢰구간과 다르다. 알려진 이상 대상 관절 선택은 EDA에만 사용했고 배포 가능한 검출 성능으로 평가하지 않았다.

## 다음 실험 및 교수님 논의

1. 전체 전류만 쓸 때와 위치/동작 단계 정보를 추가할 때의 차이를, PRE_A 정상 기준과 독립 정상·이상 테스트로 평가한다. 이번 EDA에서 선택한 신호/Action은 같은 테스트에서 성능을 최적화하는 근거로 재사용하지 않도록 탐색/평가 분리를 설계한다.
2. xArm 수령 후 실제 피드백 API·주기와 INA226 동기화부터 확인한다. 같은 반복 작업의 정상 데이터를 여러 시간/부하 조건에서 수집해 기준 변화 폭을 확인한 뒤, 정격 내 안전한 추가 하중 조건을 비교한다. Yu-Cobot의 500g 조건을 그대로 적용하지 않는다.
3. 미래 위험 예측은 유효한 시간 순서·사건 정의·리드타임 라벨이 가능한지 교수님과 결정한다. 공개 이상 setting을 임의로 이어 붙여 열화 이력으로 쓰지 않는다.
